## 快速指令集

### 开发流程
```
# 启动开发
npm run dev

# 运行测试
pytest tests/

# 类型检查
npx tsc --noEmit

# 构建
npm run build
```

### 文件操作
```
# 查找文件
glob "**/*LogViewer*"

# 搜索代码
grep "search_pattern"

# 读取文件
read "path/to/file"
```

### 修改操作
```
# 编辑代码
edit -filePath -oldString -newString

# 创建文件
write -content -filePath
```

## 常见任务参考

### 修复 TypeScript 错误
1. 读取错误定位的文件
2. 分析类型不匹配原因
3. 使用 `edit` 修复类型
4. 运行 `npx tsc --noEmit` 验证

### 添加新图层
1. 参考 `backend/loglayer/builtin/` 中的现有实现
2. 实现 `_process()` 方法
3. 注册到 `__init__.py`
4. 添加 UI Schema 到 `ui.py`

### 优化性能
1. 使用 `console.time` 或性能监控面板
2. 定位瓶颈 (渲染/计算/IO)
3. 应用优化 (缓存/懒加载/并行)
4. 验证 FPS 改善
