---
description: 一人公司 - 今日状态总览（开机仪式入口）
---

一人公司模型的**开机仪式入口**：老板每天第一条命令，看公司状态。

**输入**：`/company-report`（无参数）。

**步骤**

1. **拉取权威状态**

   ```bash
   openspec-cn list --json
   ```
   解析活跃变更、各变更任务完成进度（`N/M`）、schema 与最近更新。

2. **汇总历史报告**

   检查 `docs/company-reports/`：
   ```bash
   ls -t docs/company-reports/ | head -20
   ```
   列出最近报告（每闸门一文件），标注每个活跃变更的最后阶段与日期。

3. **汇总待提炼问题（自学习复盘输入）**

   扫描 `docs/company-reports/` 中各报告的「本次循环问题」小节：
   ```bash
   grep -l "本次循环问题" docs/company-reports/*.md
   ```
   统计含非空「本次循环问题」条目的报告数 → **待提炼问题 N 条**，列出来源报告路径，提示老板可触发提炼（`/company-init` 立项后落地）。

4. **生成今日状态摘要**

   ```
   ## 公司状态 · <日期>
   ### 活跃变更
   | 变更 | 进度 | 阶段 | 待老板决策 |
   |------|------|------|-----------|
   | <name> | N/M | <规格/实现/回归/待交付> | <项或—> |
   ...
   ### 待提炼问题（自学习）
   - [ ] 待提炼问题 N 条: <来源报告路径>（老板触发提炼 → /company-init 立项落地）
   ### 待你决策
   - [ ] Gate 2 待审批: <变更名> 报告已就绪（<报告路径>）
   - [ ] 紧急升级: <描述>
   ### 建议动作
   - 运行 /company-run <变更名> 驱动下一个循环
   - 审批 <变更名> 交付
   ```

5. **呈现给老板**

   输出一屏摘要（保持精炼，可滚动展开）。若存在待决策项或待提炼问题，明确列出并询问老板如何推进。

**护栏**
- 只读汇总，**不修改任何变更状态**
- 数据源只用 `openspec-cn list --json` + `docs/company-reports/`，不猜、不脑补
- 待决策项必须显式列出（立项 / Gate 2 审批 / 升级），让老板一眼看到该做什么
