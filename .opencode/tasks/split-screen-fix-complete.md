## 📝 技术笔记

### 关键实现细节

1. **DropZone 始终可见策略**
   - 基础状态：`bg-blue-500/5 border border-blue-300/20 opacity-40`
   - 激活状态：`bg-blue-500/30 border-2 border-blue-400 opacity-100`
   - 使用 CSS transition 实现平滑过渡

2. **快捷键冲突处理**
   - 主快捷键：`Ctrl+\` 和 `Ctrl+Shift+\`
   - 备用快捷键：`Ctrl+Shift+ArrowRight/Down`
   - 避免与浏览器默认行为冲突

3. **状态管理**
   - `isDragging`: 全局拖拽状态
   - `dragOverState`: 当前拖拽目标位置和区域
   - `paneCount`: 当前分屏数量
   - `maxPanes`: 最大分屏数量 (4)
