## 🐛 可能的问题

基于初步代码审查，识别以下潜在问题：

### 问题 1: DropZone 可见性
```tsx
// DropZone.tsx - 只在 isActive 时显示图标
{isActive && (
    <div className={iconClasses}>
        {icons[position]}
    </div>
)}
```
**问题**: 图标只在 `isActive` (拖拽到具体区域) 时显示，用户可能不知道可以拖到哪里。

### 问题 2: 拖拽触发区域
```tsx
// SplitPaneContainer.tsx
{isDragging && (
    <>
        <DropZone position="left" ... />
        ...
    </>
)}
```
**问题**: DropZone 只在 `isDragging` 时渲染，但 `isDragging` 状态可能没有正确从 hook 传递。

### 问题 3: 键盘快捷键冲突
```tsx
// App.tsx line 606-607
{ id: 'pane.splitRight', label: '向右分屏', shortcut: 'Ctrl+\\', ... }
{ id: 'pane.splitBottom', label: '向下分屏', shortcut: 'Ctrl+Shift+\\', ... }
```
**问题**: `Ctrl+\` 可能被浏览器或其他应用占用。

### 问题 4: 分屏数量限制
```tsx
enabled: panes.length < 4
```
**问题**: 最多 4 个分屏的限制是否合理？是否有明确提示？

### 问题 5: 缺少使用引导
**问题**: 用户可能不知道分屏功能的存在，或缺少使用教程。

## ✅ 建议的改进

### 短期改进 (UX 修复)

1. **增强视觉反馈**
   - 增加 DropZone 的基础可见性 (即使未激活也显示半透明指示)
   - 增加拖拽时的光标变化 (`cursor: move`)
   - 增加工具提示说明

2. **添加使用引导**
   - 首次使用时显示引导提示
   - 在空分屏区域添加明确的分屏说明
   - 添加帮助文档链接

3. **优化键盘快捷键**
   - 提供多种快捷键组合
   - 在命令面板中清晰显示快捷键
   - 允许用户自定义快捷键

4. **改进空分屏处理**
   - 新分屏创建后自动继承当前文件
   - 或显示文件选择器
   - 明确提示如何添加文件

### 中期改进 (功能增强)

1. **调整分屏布局**
   - 支持拖拽调整分屏大小
   - 支持保存/恢复分屏布局
   - 支持更多分屏模式 (网格、标签页等)

2. **增强文件管理**
   - 支持在分屏间复制文件 (而非移动)
   - 支持关闭所有其他分屏
   - 支持同步滚动

3. **性能优化**
   - 优化多分屏渲染性能
   - 懒加载非活动分屏内容
   - 优化状态更新

### 长期改进 (架构优化)

1. **状态管理重构**
   - 考虑使用 Zustand/Redux 管理复杂状态
   - 分离 UI 状态和业务逻辑
   - 增加状态持久化

2. **可访问性改进**
   - 添加键盘导航支持
   - 添加屏幕阅读器支持
   - 符合 WCAG 标准
