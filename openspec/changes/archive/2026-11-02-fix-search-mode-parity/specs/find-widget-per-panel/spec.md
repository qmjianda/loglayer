# find-widget-per-panel Delta

## MODIFIED Requirements

### Requirement: 保留高亮/过滤模式切换
系统 SHALL 在 find widget 中保留"高亮/过滤"模式切换按钮（VSCode 无此功能），以紧凑样式置于输入框左侧，用于切换仅高亮与过滤（隐藏不匹配行）两种搜索模式。切换为过滤模式后，日志视图 SHALL 仅显示当前面板搜索匹配的行；切回高亮模式或清空搜索词后 SHALL 恢复图层过滤后的完整视图。

#### Scenario: 切换搜索模式
- **WHEN** 用户点击 find widget 的高亮/过滤切换按钮
- **THEN** 搜索模式在"仅高亮"与"过滤"之间切换，按钮显示当前模式

#### Scenario: 过滤模式隐藏不匹配行
- **WHEN** 用户处于过滤模式且当前搜索有匹配
- **THEN** 日志视图只显示匹配行，不匹配行不可见
- **AND** 匹配计数、当前匹配位置与可见行集合一致

#### Scenario: 清空搜索恢复完整视图
- **WHEN** 用户处于过滤模式并清空搜索词
- **THEN** 日志视图恢复为图层过滤后的完整可见行集合

#### Scenario: 切回高亮模式恢复完整视图
- **WHEN** 用户从过滤模式切回高亮模式
- **THEN** 日志视图恢复为图层过滤后的完整可见行集合
- **AND** 匹配文本保持高亮

#### Scenario: 过滤模式与图层过滤叠加
- **WHEN** 用户已启用 FILTER 图层，并开启过滤模式搜索
- **THEN** 日志视图只显示同时满足图层过滤条件与搜索匹配的行

#### Scenario: 各面板过滤模式独立
- **WHEN** 面板 A 处于过滤模式、面板 B 处于高亮模式
- **THEN** 面板 A 隐藏不匹配行，面板 B 显示图层过滤后的完整视图
- **AND** 两个面板的搜索配置互不影响
