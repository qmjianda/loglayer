# log-viewer-rendering Specification (Delta)

## MODIFIED Requirements

### Requirement: 高亮与装饰
系统 SHALL 渲染搜索与图层产生的高亮（`highlights`）、行背景色（`rowStyle`）、当前行高亮与书签标记，且高亮区域与文字完全对齐（覆盖相同区域，无上下偏移）。搜索高亮由前端对可见行即时计算，不依赖后端下发的搜索高亮数据；图层高亮由前端渲染器按图层配置计算。

#### Scenario: 搜索高亮
- **WHEN** 存在搜索匹配的高亮标记
- **THEN** 匹配文字以高亮背景色渲染
- **AND** 高亮背景精确覆盖匹配文字，无偏移

#### Scenario: 搜索高亮前端计算
- **WHEN** 用户在查找条输入搜索词
- **THEN** 前端对可见行计算搜索高亮并即时渲染，后端不参与该高亮计算

#### Scenario: 修改搜索词即时更新高亮
- **WHEN** 用户修改搜索词
- **THEN** 可见行高亮立即按新词更新，无需等待后端管线

#### Scenario: 图层高亮与行背景
- **WHEN** 图层产生行级背景色或文字颜色
- **THEN** 系统按 `rowStyle` 渲染行背景与文字颜色
- **AND** 图层高亮由前端渲染器依据图层配置计算

#### Scenario: 书签标记
- **WHEN** 行被标记为书签
- **THEN** 该行显示书签指示标记
- **AND** 书签行样式由前端依据书签数据渲染，书签数据由后端提供
