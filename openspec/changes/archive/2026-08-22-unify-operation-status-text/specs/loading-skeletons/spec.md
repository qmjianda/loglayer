# loading-skeletons Specification Delta

## ADDED Requirements

### Requirement: 核心等待态使用统一主文案

系统 SHALL 在文件打开/索引期间使用“文件加载中”作为主状态文字，在图层流水线处理期间使用“图层处理中”作为主状态文字，在搜索期间使用“搜索中”作为主状态文字；状态栏、覆盖层和日志视图 SHALL 使用同一组文案来源。

#### Scenario: 文件加载和索引中显示统一文案

- **WHEN** 文件正在打开或构建索引
- **THEN** 文件加载相关状态表面显示“文件加载中”
- **AND** 已有百分比和文件名上下文仍然显示

#### Scenario: 图层流水线中显示统一文案

- **WHEN** FILTER、TRANSFORM 或其他图层流水线操作正在进行
- **THEN** 状态栏显示“图层处理中”
- **AND** 已有进度信息仍然显示

#### Scenario: 搜索中显示统一文案

- **WHEN** 搜索操作正在进行
- **THEN** 状态栏和日志视图的等待提示显示“搜索中”
- **AND** 搜索结果数量及现有加载视觉效果保持不变

#### Scenario: 搜索悬浮窗搜索中不显示无结果

- **WHEN** 搜索请求进行中（per-tab isSearching 为真）且结果尚未返回
- **THEN** 查找悬浮窗计数区显示“搜索中”而非“无结果”
- **AND** 计数区与输入框不进入错误态样式

#### Scenario: 错误信息优先

- **WHEN** 当前操作返回错误
- **THEN** 继续显示现有错误信息
- **AND** 错误信息不被统一等待文案覆盖

#### Scenario: 操作完成后清除等待文案

- **WHEN** 文件加载、图层处理或搜索完成
- **THEN** 对应等待文案消失
- **AND** 日志内容、结果或“就绪”状态正常显示
