## Why

图层是日志分析的核心交互手段（高亮/过滤/行着色/级别标记），但当前交互模型存在五个体验问题：右键无法直接创建带色高亮、图层标题不显示匹配内容与颜色、颜色选择器无推荐色板、图层面板占空间大且图层多时不可滚动、重命名易误触（单击已选中图层会触发折叠，与双击重命名打架）。这些问题迫使视线在正文与侧栏间反复跳转，违反"从看到日志到图层生效 <5 秒"的分析效率目标。

## What Changes

- **图层项信息显示**：图层标题行显示用户配置色标识 + 匹配文本预览（截断）+ 计数徽章，替代现有"按类型写死的图标颜色"（不再恒黄/恒蓝，显示真实配置色）。
- **右键创建路径**：日志正文右键菜单"高亮"项展开子菜单色板（16 色 + 最近使用色），点色即创建带色高亮图层；新增 `Ctrl+Shift+H` 快捷键直接高亮选中文本（用最近使用色）。拖选浮动快捷条为规划中、未实现项（后续变更）。
- **颜色选择器升级**：配置表单颜色控件增加两行 16 色推荐色板 + HEX 输入 + 最近使用 8 色（localStorage 持久化）+ 取色器（EyeDropper，Firefox 隐藏）。
- **重命名防误触**：单击图层项仅选中（不再切换折叠）；折叠只走箭头按钮；重命名 = 双击标题 + 悬停铅笔图标双入口。
- **配置区布局重构**：右侧操作台改为"属性区在上、图层列表在下"（PS 式）；属性区在选中图层时显示配置表单（紧凑单列），未选中时显示文件摘要（两用）；配置表单不再内嵌展开在图层卡内。
- **移除统计占位区**：右侧操作台"统计（第二版迭代）"占位折叠区移除。
- **预设入口迁移**：独立"预设"折叠区移除，预设列表移入"添加图层"下拉底部（点击即应用、hover 删除、超过 8 个显示"管理预设"弹层）。
- **配置生效策略**：视觉层（HIGHLIGHT/ROWTINT/LEVEL）前端实时生效；数据层（FILTER/TRANSFORM）配置输入 400ms 防抖后触发后端重算。
- **书签区保留**：保持折叠态默认收起，行高压缩。

## Capabilities

### New Capabilities

- `layer-interaction`: 图层作为日志分析主交互手段的完整交互契约——创建路径（右键子菜单色板 / 快捷键）、颜色选择器（推荐色板 / 最近使用 / HEX / 取色器）、图层项信息显示（配置色标识 + 匹配文本预览 + 计数）、重命名与选中语义（单击选中 / 再击取消 / 双击 + 铅笔重命名）、配置生效策略（视觉层实时 / 数据层防抖）。

### Modified Capabilities

- `right-inspector-panel`: 图层区布局改为"属性区在上、列表在下"（选中图层显示配置、未选中显示文件摘要）；移除"统计占位区"；移除独立"预设"折叠区（预设迁入添加图层下拉）；书签区保持折叠但行高压缩。

## Impact

- **前端**：`frontend/src/components/LayersPanel.tsx`（信息密度/布局/重命名/分区头）、`DynamicUI/DynamicForm.tsx` + `InputMapper.tsx` + `ColorPicker.tsx`（紧凑表单/色板升级）、`InspectorPanel.tsx`（属性区上移/移除统计/预设迁入下拉）、`hooks/useCommands.ts`（Ctrl+Shift+H）、`LogViewer.tsx`（右键色板子菜单）、`InspectorBookmarks.tsx`（行高压缩）。
- **后端**：基本无改动（`ui_schema`/`registry` 不变；颜色/色板/最近使用色均为前端概念）。
- **无破坏性 API 变更**：REST/WS 接口不变。
