## Context

前端代码库中存在 3 个未被使用的 utils 文件，这些文件虽然存在但没有被任何组件导入或使用。删除它们不会影响现有功能。

## Goals / Non-Goals

**Goals:**
- 安全删除 3 个未使用的 utils 源文件
- 安全删除 2 个对应的测试文件
- 验证删除后项目可正常编译和运行

**Non-Goals:**
- 不修改业务逻辑
- 不删除组件代码
- 不进行大规模重构

## Decisions

### 1. 删除前验证策略
- 使用 grep 再次确认每个文件未被引用
- **决定**: 先验证再删除

### 2. 测试文件处理
- 源文件删除后，对应的测试文件也必须删除
- **决定**: 批量删除相关测试文件

## Risks / Trade-offs

| 风险 | 级别 | 缓解措施 |
|------|------|----------|
| 误删正在使用的代码 | 低 | 删除前用 grep 确认无引用 |
| 编译失败 | 低 | 删除后运行 npm run build 验证 |

## Migration Plan

1. 使用 grep 再次确认每个文件未被引用
2. 删除 3 个 utils 源文件
3. 删除 2 个测试文件
4. 运行 `npm run build` 验证
5. 运行 `npm test` 确认测试通过
